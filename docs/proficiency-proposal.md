# 熟练度按成功率判定的建议方案

状态：已按本方案实现，本文保留为规则说明。

## 建议

使用「近期独立默写成功率」判断每个单词的拼写熟练度。练习次数保留为历史统计；等级由成功率决定，样本量只用于判断评估是否足够可靠。

本指标反映近期独立拼写的稳定性，不直接代表长期记忆或对词义的掌握程度。

## 当前问题

- 当前状态由单次结果覆盖：无错就变为熟悉，错误 3–4 次变为模糊，错误不少于 5 次或使用提示变为忘记。
- 成功与失误统计混合了学习和默写模式，无法区分看着答案输入与独立回忆。
- 使用拼写提示后无错完成仍计入成功次数，悬停查看答案也没有纳入现有提示判定。
- 因此不能直接把旧的成功次数除以成功与失误总次数，作为新的独立默写成功率。

## 方案比较（从简单到复杂）

| 方案                       | 优点                           | 局限                                               | 建议             |
| -------------------------- | ------------------------------ | -------------------------------------------------- | ---------------- |
| 全部历史成功率             | 容易理解，实现简单             | 早期错误长期拖低结果，大量旧成功也可能掩盖近期退步 | 作为历史统计     |
| 最近 20 个有效结果的成功率 | 易于解释，能逐步反映进步和退步 | 少量样本需要暂缓定级，旧结果退出窗口时会有变化     | 首版采用         |
| 对近期结果加权的成功率     | 对最近的变化更敏感             | 权重需要调校，百分比不再是直观的成功占比           | 后续有需要再评估 |

## 首版规则

### 1. 定义有效结果

- 以单个单词的一次完整默写机会为单位，不按正确字母数计算。
- 只有从开始到结束都处于整词隐藏模式的测验参与评估；普通学习和部分字母隐藏练习保留练习统计。
- 无拼写错误，且没有查看拼写提示或悬停答案，完整写对记为成功。
- 出现拼写错误或查看答案记为失败；之后改对或补打不把这次结果改成成功。
- 失败一经发生，本次结果即固定；退出页面不应抹掉已经发生的失败。没有作答、没有看答案就切换或退出不计入。
- 听正常题目发音不算查看拼写答案；不加入输入速度门槛。
- 同一词在一轮中的连续重复、错误后的立即重打合并为一个结果。返回该词也不新增评估机会；重新开始一轮才有新的机会。
- 学习模式切换到默写模式不能把当前已经展示过的词立即作为独立测验，需从下一次新的测验机会开始。

### 2. 计算近期成功率

每个单词保留最近最多 20 个有效结果：

**近期成功率 = 窗口内成功结果数 ÷ 窗口内全部有效结果数 × 100%。**

20 是首版建议窗口，不要求必须练满 20 次才出结果。新结果进入后移除最旧结果，较早的失败或成功都不会永久影响等级。

### 3. 映射等级

正式等级仅保留「生疏、模糊、熟悉」三档，将原建议中的「熟悉」和「熟练」合并为「熟悉」。「未评估」和「初步评估」只是评估状态，不属于熟练度档位。

| 条件                     | 显示                               |
| ------------------------ | ---------------------------------- |
| 尚无有效结果             | 未评估                             |
| 有效结果少于 5 个        | 初步评估，暂不确定等级 |
| 成功率低于 60%           | 生疏                               |
| 成功率达到 60%，低于 80% | 模糊                               |
| 成功率达到 80%           | 熟悉                               |

上述比例和最少样本量是首版产品参数，后续可根据实际体验调整，并非经过验证的记忆能力分界线。少量样本暂缓定级用于避免一次答对就判为熟悉；达到最少样本量后，等级完全由成功率决定。

使用未四舍五入的比率判定等级，页面不展示当前单词的成功率数值。

例：最近 20 次成功 16 次为 80%，判为熟悉；成功 12 次为 60%，判为模糊；即使历史练习很多次，近期只有 50% 仍判为生疏。

### 4. 页面展示

常规显示示例：**熟练度：熟悉**。成功率仅用于熟练度判定，不单独展示「近期成功率」及其数值。

初期显示示例：**初步评估**。说明为「再练习一些，评估会更准确」。

用简短说明解释「根据近期独立默写表现评估」。保留原有练习历史，不在常规界面展示存储、迁移、窗口维护等实现细节。不要再用“忘记”描述所有低成功率情况。

## 实施顺序

1. 先统一新评估中成功、失败和有效测验的定义，覆盖提示、悬停答案、模式切换和连续重复。
2. 新增近期结果记录与纯计算函数，替换单次表现决定等级的逻辑。
3. 同步状态面板、词表颜色与说明；更新备份和恢复兼容处理。
4. 保留旧历史数据，新评估从可验证的新结果开始积累；不把缺少模式和提示信息的旧计数伪装成独立默写记录。

## 实施时的验证重点

- 提示后零错误、悬停看答案和失败后重打均不能提高本次评估结果。
- 完成回调、返回单词、刷新页面及多次重复不会重复计入同一测验。
- 窗口长度限制、等级边界和少量样本状态一致；页面不展示当前单词的成功率。
- 普通学习与部分隐藏模式不影响独立默写等级。
- 原有历史、进度、旧备份恢复及新备份往返兼容正常。
